## 1. 판매용 DB 설치 (한 번만)

1. Supabase(판매용) → **SQL Editor → New query**
2. `supabase/saas_fresh_setup.sql` 전체를 붙여넣고 **Run**
3. 끝에 오류 없이 `Success` 가 나오면 완료

> 이후 새 마이그레이션(019~)이 생기면 그 파일만 SQL Editor 에서 실행하세요.
> 합본을 다시 만들려면 `python scripts/build-saas-setup.py`.

## 2. 판매용 Supabase 인증 설정

**Authentication → URL Configuration**
- Site URL: `https://today-jaego.vercel.app`
- Redirect URLs: `https://today-jaego.vercel.app/auth/callback` 추가
- 바로가기: https://supabase.com/dashboard/project/cmelpqogzbftrvatkutf/auth/url-configuration

**Authentication → Providers → Email**
- **Confirm email 끔** (운영 방침: 가입 즉시 로그인 → 14일 무료 체험 → 결제)
- 나중에 인증을 켜려면 먼저 도메인 + **Settings → Auth → SMTP** 연결 (무료 기본 메일은 팀원 주소로만 발송)

## 3. 판매용 배포

같은 GitHub 저장소(`koreagoldstar/jaego-two`)로 새 프로젝트를 만들고 환경 변수를 넣습니다.

```
NEXT_PUBLIC_SUPABASE_URL=https://cmelpqogzbftrvatkutf.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=판매용 Supabase → Settings → API → anon public 키
NEXT_PUBLIC_SAAS_MODE=1
```

- **베타(결제 받기 전)**: Vercel 무료(Hobby)로 새 프로젝트 만들어도 됩니다.
- **첫 유료 고객부터**: Vercel Pro 로 올리거나 Cloudflare 등 상업 이용 가능한 무료 호스팅으로 옮기세요. (Vercel Hobby 는 상업적 이용 금지)

## 4. 무료 DB 일시정지 방지

Supabase 무료 프로젝트는 7일 동안 접속이 없으면 멈춥니다.
`.github/workflows/saas-keepalive.yml` 이 매일 한 번 접속합니다.

GitHub 저장소 → **Settings → Secrets and variables → Actions → New repository secret**
- 이름: `SAAS_SUPABASE_ANON_KEY`
- 값: 판매용 anon public 키

등록 후 **Actions → saas-supabase-keepalive → Run workflow** 로 한 번 실행해 초록색이 뜨는지 확인하세요.

## 운영 메모

- **도입 문의 확인**: 판매용 Supabase → Table Editor → `inquiries`
- **요금제 변경 / 체험 → 이용중 전환**: Table Editor → `workspaces` 에서 해당 회사의 `plan_id`(`basic`/`standard`/`pro`), `status`(`trial`/`active`) 수정
- **요금·한도 변경**: `plans` 테이블과 `lib/saas/plans.ts` 를 같이 고치세요
- **사업자 정보**(사이트 하단): `lib/saas/site.ts`

## 5. 새 문의·가입 알림 메일 (breakbug@naver.com)

새 문의가 접수되거나 새 회사가 가입하면 `breakbug@naver.com` 으로 메일이 갑니다. [Resend](https://resend.com) 무료(월 3,000통) 사용.

1. https://resend.com 에서 **breakbug@naver.com 으로 가입** (자체 도메인이 없으면 가입한 이메일로만 받을 수 있음)
2. **API Keys → Create API Key** → 권한 `Sending access` → 복사 (`re_...`)
3. Vercel `today-jaego` 프로젝트 → **Settings → Environment Variables** 에 추가 후 **Redeploy**
   - `RESEND_API_KEY` = 복사한 키
4. 문의하기에서 테스트 문의를 보내 메일이 오는지 확인 (스팸함도 확인)

- 받는 주소를 바꾸려면 `NOTIFY_EMAIL` 환경 변수 추가
- 나중에 자체 도메인을 Resend 에 연결하면 `NOTIFY_FROM=오늘의 재고 <noreply@도메인>` 으로 보내는 주소 변경 가능
- 키가 없거나 발송이 실패해도 문의·가입은 정상 처리됩니다 (Supabase `inquiries`·`workspaces` 에 저장)
